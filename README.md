# Computational Topology – Labyrinth Generation

This repository contains the complete solutions for the group project on
generating labyrinths in 2D, on surfaces, and in 3D.

## Contents / Solutions

- **2D Labyrinths**
  - Random edge addition, random walks, and edge erasing
  - Constrained and unconstrained analyses
  - Experimental comparisons and visualizations

- **Surfaces (Torus & Klein Bottle)**
  - Labyrinth generation with non-trivial \( H_1 \)
  - Examples and combined visualizations

- **3D Labyrinths**
  - 3D maze generation
  - Connectivity and homological interpretation
  - Resulting visual outputs

Each directory corresponds to one of these solution areas and contains the
relevant generation code, tests, and images.
